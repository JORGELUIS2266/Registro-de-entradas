Descripción del Proyecto

El presente proyecto consiste en el desarrollo de un Sistema de Control de Entradas para el Instituto Tecnológico de Tlaxiaco, implementado como una aplicación de escritorio desarrollada en C# con Windows Forms y conectada a una base de datos SQL Server. El sistema permite registrar, consultar, modificar y eliminar información de alumnos y profesores, así como gestionar el acceso mediante un sistema de autenticación con roles diferenciados (superusuario y usuario estándar).

El sistema fue diseñado para operar tanto en modo local (cuando la base de datos reside en la misma máquina) como en modo de red (cuando varios clientes se conectan a un servidor centralizado), e incluso en la nube. Cuenta con módulos para la gestión de alumnos, gestión de profesores, control de usuarios y generación de reportes exportables a Excel.

Problemática Identificada

El Instituto Tecnológico de Tlaxiaco carecía de un sistema digital centralizado para el control de asistencia y registro de entradas de sus estudiantes y docentes. El proceso se realizaba de forma manual, lo que generaba inconsistencias en los datos, pérdida de información y dificultades para generar reportes confiables. Esta situación demandaba el desarrollo de una solución tecnológica que automatizara y centralizara dicho proceso.

Objetivo General y Específicos

Objetivo General

Desarrollar e implementar un sistema de escritorio para el control de entradas del Instituto Tecnológico de Tlaxiaco, que permita gestionar de manera eficiente el registro de alumnos y profesores, automatizando los procesos de captura, consulta, modificación y eliminación de datos, con acceso controlado por roles de usuario y conectividad a base de datos SQL Server en red local.

Objetivos Específicos

  1. Diseñar y estructurar una base de datos relacional en SQL Server que almacene la información de alumnos, profesores y usuarios del sistema de manera organizada e íntegra.
  2. Desarrollar módulos CRUD (Crear, Leer, Actualizar, Eliminar) para la gestión completa de registros de alumnos y profesores desde una interfaz de usuario amigable en Windows Forms.
  3. Implementar un sistema de autenticación con dos niveles de acceso: superusuario (acceso total) y usuario estándar (acceso restringido), garantizando la seguridad de la información.
  4. Diseñar una arquitectura cliente-servidor que permita la operación del sistema en red local, posibilitando que múltiples estaciones de trabajo accedan a la misma base de datos centralizada.
  5. Integrar funcionalidades de validación de datos en el frontend para asegurar la calidad e integridad de la información ingresada al sistema.
  6. Implementar la funcionalidad de exportación de datos a formato Excel, facilitando la generación de reportes por parte del personal administrativo.
  7. Desarrollar un módulo de gestión de usuarios que permita al superusuario crear, activar, desactivar y monitorear el estado de conexión de los usuarios en tiempo real.

Justificación

La implementación de un Sistema de Control de Entradas en el Instituto Tecnológico de Tlaxiaco responde a una necesidad real y urgente dentro de la institución: la modernización de los procesos administrativos relacionados con el registro y control de acceso de su comunidad estudiantil y docente.

En la actualidad, la gestión manual de asistencias y entradas conlleva múltiples problemas operativos. La falta de un sistema centralizado provoca duplicidad de información, errores en el registro de datos personales de alumnos y profesores, dificultad para generar reportes estadísticos y una inversión innecesaria de tiempo por parte del personal administrativo. Ante esta situación, el desarrollo de una solución tecnológica eficiente se convierte en una prioridad institucional.

Desde el punto de vista tecnológico, el uso de C# con .NET Framework y Windows Forms garantiza una aplicación robusta, de bajo consumo de recursos y compatible con el parque computacional existente en la institución. La elección de SQL Server como gestor de base de datos proporciona confiabilidad, seguridad transaccional y capacidades avanzadas de consulta para el manejo de grandes volúmenes de datos.

La arquitectura cliente-servidor implementada permite que el sistema sea utilizado simultáneamente desde múltiples equipos de la red interna del plantel, sin requerir infraestructura costosa ni conexión a Internet. Esto asegura la continuidad del servicio incluso ante fallas de conectividad externa.

El sistema también contribuye a la formación profesional del residente, ya que involucra el dominio de tecnologías ampliamente demandadas en el mercado laboral como el desarrollo de aplicaciones de escritorio, diseño de bases de datos relacionales, programación orientada a objetos y arquitecturas de software multicapa.

Por todo lo anterior, el desarrollo de este sistema representa una solución pertinente, viable y de alto impacto para la institución, alineada con los objetivos del programa de residencias profesionales del Tecnológico Nacional de México.
