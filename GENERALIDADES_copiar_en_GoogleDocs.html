Descripción General del Proyecto

El Sistema de Control de Entradas es una aplicación de escritorio desarrollada en el lenguaje C# sobre .NET Framework 4.7.2 con Windows Forms, conectada a una base de datos SQL Server Express, diseñada específicamente para satisfacer las necesidades administrativas del Instituto Tecnológico de Tlaxiaco. El sistema centraliza de forma digital el registro y gestión de la comunidad estudiantil y docente de la institución, permitiendo realizar operaciones de alta, consulta, modificación y baja de registros de manera eficiente y confiable.

El sistema cuenta con un mecanismo de autenticación con dos niveles de acceso diferenciados: superusuario, con control total del sistema, y usuario estándar, con permisos restringidos a consultas y registros. Opera bajo una arquitectura cliente-servidor que permite a múltiples equipos de trabajo conectarse simultáneamente a una base de datos centralizada a través de la red local del plantel. Entre sus funcionalidades destacan la validación dinámica de datos, la exportación de listas a formato Excel y el monitoreo en tiempo real del estado de conexión de los usuarios del sistema.

Problemática Identificada

El Instituto Tecnológico de Tlaxiaco carecía de un sistema digital centralizado para el registro y control de entradas de su comunidad estudiantil y docente. Los procesos administrativos relacionados con el registro de alumnos y profesores se llevaban a cabo de manera manual, utilizando hojas de cálculo o registros en papel, lo que generaba múltiples problemas operativos: inconsistencia en los datos registrados, duplicidad de información, pérdida de registros históricos, dificultad para generar reportes estadísticos y una inversión excesiva de tiempo por parte del personal administrativo.

Aunado a lo anterior, la falta de control de acceso al sistema de registro permitía que cualquier persona pudiera modificar o eliminar información sin ningún tipo de auditoría o restricción. La ausencia de un historial de conexiones y la imposibilidad de identificar quién realizó cada operación representaban un riesgo para la integridad de los datos institucionales. Ante esta problemática, se identificó la necesidad urgente de desarrollar e implementar una solución tecnológica que automatizara, centralizara y asegurara la información, mejorando la eficiencia operativa y la seguridad de los datos del plantel.
